# capybara-clicker
A clicker game where you click the capybara and upgrade

<img src="images/capybara.png" alt="drawing" width="200"/>

## Demo URL
https://222erik.github.io/capybara-clicker/

## Features
- Skins
- Animations/effects
- CPS counter
- Cheat buttons
- A shop

## How to play
Click the capybara and buy shop items, use the debug buttons if you get stuck.
